# API домашних рецептов

Учебный HTTP-сервер на Node.js без сторонних зависимостей. Данные хранятся в
`data.json`, тема записей — домашние рецепты.

## Запуск

```bash
node server.js
```

Сервер доступен по адресу `http://localhost:3000`.

## Маршруты

| Метод | Путь | Результат |
| --- | --- | --- |
| GET | `/` | JSON-описание API, код `200` |
| GET | `/items` | Все записи из `data.json`, код `200` |
| GET | `/items?category=Супы` | Рецепты выбранной категории, код `200` |
| GET | `/items/:id` | Одна запись по номеру, код `200`; если запись отсутствует — `404` |
| POST | `/items` | Добавляет запись и возвращает её, код `201` |

Для POST нужен JSON с непустым полем `title`. Например:

```json
{"title":"Овощное рагу","category":"Основные блюда","cuisine":"Русская","time":45}
```

Если JSON некорректен или отсутствует `title`, сервер возвращает `400`.
Ошибки чтения `data.json` возвращают `500`, остальные неизвестные маршруты —
`404`. Все ответы API имеют формат JSON.
